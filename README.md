# Digital Clock using Verilog

A 24-hour digital clock designed using Verilog HDL with a programmable alarm.

## Features
- 24-hour format
- Seconds, minutes and hours counters
- Automatic rollover at 59 seconds, 59 minutes and 23 hours
- Asynchronous reset
- Programmable alarm

## Tools
- Verilog HDL
- Xilinx Vivado

## Files
- `DigitalClock.v` – RTL design
- `Digital_clock_tb.v` – Testbench
